# Тренинг «Юнит-тестирование + TDD»

Готовые материалы для проведения тренинга: теория и практические упражнения находятся в одном репозитории.

- [Программа тренинга](overview.md)
- [Теория: день 1](theory/day1/)
- [Теория: день 2](theory/day2/)
- [Практические упражнения](practice/)

## Быстрый старт

```bash
git clone https://github.com/nchursin/ut-tdd-training.git
cd ut-tdd-training
```

Каждое упражнение в `practice/` открывается в IDE как отдельный проект. Инструкции по настройке и запуску находятся в README соответствующего упражнения.

В стартовом состоянии тесты Gilded Rose намеренно красные: placeholder-тесты являются частью каты, а не ошибкой окружения.
